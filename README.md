# OpCameraMute

Shizukuを使って、OPPO端末の標準カメラのシャッター音を無音化するAndroidアプリです。

[Google Play版「オッポカメラ無音化（非公式）」](https://play.google.com/store/apps/details?id=com.izumiapps.cameramute)も同じ開発者が配信しています。

## 必要な環境

- Android 15以上
- ADB（ワイヤレスデバッグ）方式で起動した [Shizuku](https://shizuku.rikka.app/)
- Shizukuで本アプリを許可
- 本アプリの通知を許可
- サイレントまたはバイブモード

root方式のShizukuには対応していません。機種名による利用制限は設けていませんが、端末側APIと音設定の現在値を確認してから操作します。無音補助をオンにする前に、変更前の音設定を保存します。利用には共通の注意事項への同意が必要です。

## 使い方と復元

1. Shizukuを準備します。OPPOでは「認可の監視を無効化」などの開発者設定が必要な場合があります。アプリ内の準備ガイドを確認してください。
2. 通知を許可し、サイレント／バイブへ切り替えて注意事項に同意します。
3. 「無音補助をオン」を押し、標準カメラの写真・動画の実際の音を確認します。
4. 使用後は「純正状態に戻す」を押し、実際の音も確認します。通知とクイック設定タイルからも操作できます。

アプリを閉じる、強制停止する、削除するだけでは音設定は元へ戻りません。Shizukuが切断された場合は再接続して復元してください。

アプリの削除やデータ消去の前に、必ず「純正状態に戻す」を実行してください。削除やデータ消去で変更前の記録が失われると、未検証の端末ではアプリから元へ戻せなくなります。その場合は端末を再起動し、設定と写真・動画の実際の音を確認してください。再起動で元に戻るとは限りません。強制停止やアプリの更新では状態通知も消えることがありますが、音設定は変更されたまま残ります。通知が消えた場合も、アプリを開いて状態を確認してください。

未検証の端末・OSビルドでは、本アプリが保存した変更前の記録がないと復元しません。例外として、上記のPlay版で確認したモデル・OSビルド・ビルド識別情報が一致する端末では、記録がなくても確認済みの標準値へ戻せます。設定値の一致だけでは、実際の音や他の音への影響は判定できません。

端末全体の強制可聴音の設定を変更するため、カメラ以外の音にも影響する可能性があります。すべてのカメラ音の無音化や、アラーム・緊急音の動作を保証しません。

## Play版との使い分け

本リポジトリのアプリIDは `com.izumiapps.cameramute.free` です。Play版とは別のアプリとしてインストールされ、同意・復元記録を引き継ぎません。アプリ名とアイコンはPlay版と同じため、同じ端末に両方を入れると見分けにくくなります。

Play版や他の音設定変更アプリで先に音設定を元へ戻してから使ってください。同時操作は避けてください。

## ビルド

JDK 21、Android SDK Platform 36、Build Tools 36.0.0を用意します。Android Studioで開くか、SDKの場所をローカルの `local.properties` に設定してください。

```properties
sdk.dir=/path/to/Android/sdk
```

```sh
./gradlew :app:testDebugUnitTest :app:testReleaseUnitTest :app:lintDebug :app:assembleDebug :app:assembleDebugAndroidTest :app:assembleRelease
```

Debug APK: `app/build/outputs/apk/debug/app-debug.apk`
Release APK: `app/build/outputs/apk/release/app-release-unsigned.apk`（未署名）

署名鍵・署名設定は同梱していません。Release版をインストールするには、ご自身の鍵で別途署名してください。
